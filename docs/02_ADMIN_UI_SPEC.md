# 管理画面仕様 v1

## 1. 基本方針

- 表示言語は日本語。
- 通常運用でコマンド、PowerShell、CLIを要求しない。
- デスクトップPCのローカルブラウザから使用する。
- 画面遷移を増やさず、左メニュー＋タブ切替を基本とする。
- ゲーム中に安全な設定だけ即時反映し、次回ゲーム適用の値は明示する。
- 危険操作は確認ダイアログと操作結果表示を必須とする。
- Minecraft内で必要な操作は「管理画面で登録モード選択 → ゲーム内でクリック」に統一する。

## 2. 画面構成

| 画面 | 主な用途 |
|---|---|
| ダッシュボード | サーバー、ゲーム、参加者、使用マップ、警告の確認 |
| ゲーム操作 | 受付、準備開始、攻略開始、停止、再開、中止、妨害 |
| プレイヤー | オンライン一覧、参加・除外、管理者許可 |
| マップ | ZIP登録、有効化、検証、複製、削除、次回固定 |
| マップ設定 | 地点・範囲・コア・敵ゾーン・ショップの登録 |
| バランス | 人数倍率、コアHP、敵、タイマー、資源再生成 |
| 装備・ショップ | スターターキットと取引編集 |
| 履歴・ログ | ゲーム結果、管理操作、警告、エラー |
| システム | ポート、バックアップ、診断、サーバー安全停止 |

## 3. ダッシュボード

常時表示：

- Paper接続状態
- プラグインバージョン
- 現在のゲーム状態
- 現在sessionId
- 経過時間
- 参加人数 `n / 4`
- 使用中マップ
- 通常コア進捗・最終コアHP
- 敵数と上限
- 未解決警告

状態に応じて押せる主ボタンを1つ強調する。

- `IDLE`：参加受付を開始
- `RECRUITING`：ゲーム準備開始
- `PREPARING`：攻略を今すぐ開始
- `ACTIVE`：一時停止
- `PAUSED`：再開
- 異常時：安全に回収

## 4. ゲーム操作

### 4.1 参加受付

- 受付開始・終了
- 参加者一覧
- オンラインプレイヤーから追加・除外
- 最大人数変更（v1は1～4の範囲）
- 次回マップ固定の表示

### 4.2 実行中操作

- 攻略開始
- 一時停止・再開
- ゲーム中止
- 参加者をファームへ救出
- 所有敵を全削除
- 選択したコアを再生成（診断権限、確認必須）

### 4.3 妨害パネル

- 暗闇
- 浮遊
- ホットバー変更
- 追加ウェーブ
- 対象：全員 / ランダム1人
- 発動結果と除外理由を直下表示

任意Potion Effect、任意コマンド、自由入力によるEntity生成は提供しない。

## 5. マップ登録

### 5.1 ZIPアップロード

1. 「マップを追加」を押す。
2. `.zip`をドラッグ＆ドロップまたはファイル選択する。
3. 表示名と英数字・ハイフンのmapIdを入力する。
4. 展開前検証結果を確認する。
5. インポートを実行する。

検証表示：

- ZIPサイズ・予想展開サイズ
- Java版ワールド構造の検出
- `level.dat`の存在
- 入れ子ディレクトリの自動補正可否
- 禁止パス・シンボリックリンク・重複mapId
- 対応外または破損の理由

### 5.2 マップ一覧

- 表示名、mapId、登録日時、検証状態、有効/無効
- 必須設定の達成数
- テスト読込
- セットアップ開始
- 次回だけ固定
- 複製（設定のみ複製）
- 削除（名前再入力＋確認）

原本削除は、そのマップの一時ワールド・セットアップセッション・進行ゲームがない場合だけ許可する。

## 6. マップセットアップ

### 6.1 セッション開始

1. マップを選ぶ。
2. 操作するオンライン管理者を選ぶ。
3. 「セットアップ開始」を押す。
4. プラグインが原本からセットアップ用ワールドを作成し、管理者を転送する。
5. 管理画面にリアルタイムの登録状況を表示する。

### 6.2 登録操作

地点登録：

1. 管理画面で項目を選ぶ。
2. 「地点を選択」を押す。
3. Minecraft内で対象ブロックを右クリックする。
4. 座標・向き・ワールドを管理画面に仮表示する。
5. 「確定」で保存する。

範囲登録：

1. 管理画面で項目を選ぶ。
2. 「範囲を選択」を押す。
3. Minecraft内で角A、角Bを順に右クリックする。
4. サイズとブロック数、重複警告を表示する。
5. 「確定」で保存する。

クリックにはセッション専用のセットアップツールを使用する。通常アイテムの破壊・設置は行わない。

### 6.3 設定項目

- ファーム範囲・復帰地点
- 攻略入口
- 通常コア候補（追加・並び替え・削除）
- 最終コア
- 最終ゲート範囲
- 最終エリア範囲
- 最終入口/ワープブロック
- チェックポイント（順序あり）
- 敵スポーンゾーン（名前・範囲・Mob設定）
- 資源ゾーン（鉱石/農作物）
- ショップ地点

### 6.4 完了

- 「検証」で不足・重複・危険配置を一覧化する。
- 必須項目が揃うまで有効化できない。
- 「保存して終了」で設定を原子的に保存し、セットアップワールドを破棄する。
- 「破棄して終了」では未保存変更を捨てる。
- 原本のブロック変更はv1セットアップでは保存しない旨を画面に常時表示する。

## 7. バランス設定

設定項目には次を表示する。

- 現在値
- 初期標準値
- 許容範囲
- 適用タイミング（即時 / 次回ゲーム）
- 初期値に戻すボタン

設定グループ：

- 準備時間、クリア演出時間、再接続猶予
- 人数別倍率
- 通常/最終コアHP、1打上限
- 敵構成、上限、周期、距離
- 資源再生成時間
- 妨害時間・強度・技術的受付間隔
- UIメッセージ表示時間

ゲーム中変更不可の値は入力を無効化し「次回ゲームから変更できます」と表示する。

## 8. 装備・ショップ編集

- Minecraft Namespaced Keyを候補検索して選択する。
- 個数、表示名、Lore、エンチャント、壊れない設定を編集する。
- 存在しないアイテム、最大スタック超過、負数を保存できない。
- ショップ取引は並び替え、複製、有効/無効切替が可能。
- 保存前に取引プレビューを表示する。

## 9. 履歴・ログ

- ゲーム履歴を日時、マップ、終了理由で絞り込む。
- 1ゲームの結果詳細を表示する。
- ログはINFO/WARN/ERRORとカテゴリで絞り込む。
- 技術詳細は折りたたみ、最初に日本語の原因と対処を表示する。
- 認証情報、Cookie、ファイルシステムの不要な絶対パスは表示しない。

## 10. エラー表示

すべての操作は次のいずれかを返す。

- 成功：何が完了したか。
- 受付済み：進行状況とキャンセル可否。
- 入力エラー：該当欄と直し方。
- 状態競合：現在状態と実行可能な次操作。
- 内部エラー：安全な日本語要約、追跡ID、再試行/回収ボタン。

画面を再読込しても長時間処理の状態を復元する。

## 11. 起動と終了の最終形

- 「Orushio PVEを起動」ショートカットをダブルクリックする。
- Paperと管理画面が起動し、準備完了後にブラウザが自動で開く。
- 二重起動時は新規起動せず、既存管理画面を開く。
- 終了は管理画面の「サーバーを安全に停止」から行う。
- ゲーム中の停止は確認後、参加者復元と一時ワールド回収を先に行う。
- コンソール画面を通常操作に使わせない。

ショートカット/ランチャー作成は最終運用Phaseで行い、ゲームCoreと混在させない。
