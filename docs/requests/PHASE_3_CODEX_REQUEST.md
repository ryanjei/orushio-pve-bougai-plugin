# 3. Phase 3の目的

Phase 3では、

**配布Minecraft Javaワールドを管理画面から安全に登録し、ゲーム用一時ワールドとして利用できる基盤**

を完成させます。

また、

**ゲーム内で地点・範囲を登録し、マップごとのセットアップ情報を保存できる状態**

まで実装してください。

PvEゲーム本体はまだ実装しません。

---

# 4. Phase 3完成条件

最低限以下を満たしてください。

1. 管理画面からJava版ワールドZIPを登録できる
2. ZIPを安全に検証・展開できる
3. 登録した原本ワールドを直接ゲームで変更しない
4. ゲーム用一時コピーを作成できる
5. 一時ワールドを安全にロードできる
6. アンロードできる
7. 所有確認後に一時ワールドを削除できる
8. 登録マップを有効/無効管理できる
9. 有効マップからランダム選択できる
10. 候補が2個以上なら直前マップを避けられる
11. 次回使用マップを1回だけ固定できる
12. 管理画面からマップセットアップを開始できる
13. ゲーム内操作で地点・範囲を登録できる
14. 必須項目不足のマップを有効化できない
15. セットアップを保存終了できる
16. セットアップを破棄終了できる
17. 異常終了後に残った「このプラグイン所有」の一時ワールドだけを回収できる

# 5. マップ原本保護

最重要要件です。

登録されたマップ原本をゲーム用ワールドとして直接ロード・変更してはいけません。

基本構造：

`登録ZIP`

↓

`検証済み原本`

↓

`ゲーム開始時に一時コピー作成`

↓

`一時コピーをPaperへロード`

↓

`ゲーム終了時アンロード`

↓

`所有確認`

↓

`一時コピー削除`

としてください。

原本は再利用可能な初期状態として維持してください。

---

# 6. ZIP安全検証

最低限以下を拒否してください。

- Zip Slip
- `../`
- 絶対パス
- 不正なパス
- シンボリックリンク等による展開領域外参照
- 展開ファイル数上限超過
- 展開サイズ上限超過
- 不正ZIP
- 空ZIP
- Minecraftワールドとして成立しないもの

巨大ZIPによるディスク圧迫にも対策してください。

上限値は既存仕様があればそれを優先し、未定義の場合は設定可能な安全値を採用してください。

---

# 7. ZIP構造

一般的な配布ワールドで、

ZIP直下がワールド本体の場合と、

`map-name/level.dat`

のように1階層ディレクトリが挟まっている場合を考慮してください。

無制限に深い階層探索はしないでください。

Minecraftワールド本体を安全に特定してください。

# 10. マップ削除

登録済みマップの削除は慎重に扱ってください。

削除対象が、

**このプラグインが管理しているマップであること**

を確認してください。

パス文字列だけを信用して任意ディレクトリを削除してはいけません。

ゲーム使用中、一時コピー使用中、セットアップ中など、安全に削除できない状態では拒否してください。

---

# 11. ランダムマップ選択

有効マップだけを候補としてください。

候補が：

- 0件 → 開始不可
- 1件 → そのマップ
- 2件以上 → 原則として直前マップを除外

としてください。

ランダム選択処理はテスト可能なDomain/Application側へ置いてください。

---

# 12. 次回マップ固定

管理画面から、

**次の1ゲームだけ使用するマップ**

を指定できるようにしてください。

固定したマップが実際に選択された時点で固定を解除してください。

無効化・削除等で使用不能になった場合の扱いも安全にしてください。

永久固定にはしません。

---

# 13. 一時ワールド

ゲームまたはセットアップで原本を使用する場合、必ず一時コピーを作成してください。

一時ワールドには、

- プラグイン所有であること
- 元mapId
- session/setup等の用途
- 一意な識別子

を安全に識別できる仕組みを持たせてください。

他プラグインやユーザーが作成したワールドを誤削除しないことを最優先にしてください。

---

# 14. Paperへのロード/アンロード

ワールドロード・アンロードなどPaper APIのスレッド制約を守ってください。

Phase 2で整備した`GameThreadExecutor`等、既存の安全な実行経路を再利用してください。

HTTPスレッドからPaper APIを直接操作しないでください。

時間のかかるファイルコピー・ZIP展開等をPaperメインスレッド上で行ってはいけません。

# 21. 異常終了回収

Paperやプラグインが異常終了し、一時ワールドが残る可能性を考慮してください。

**明確にこのプラグイン所有と証明できる一時ワールドだけ**

を検出・回収してください。

所有確認できないディレクトリは削除しないでください。

自動削除が危険な場合は診断モード等へ遷移させ、安全側へ倒してください。
